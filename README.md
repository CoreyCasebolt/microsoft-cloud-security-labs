This repository contains hands-on labs focused on Microsoft cloud security, Azure administration, identity management, monitoring, governance, automation, and cost control. These projects were built to strengthen practical skills with Azure, Microsoft Entra ID, Microsoft Defender for Cloud, Microsoft Sentinel, Conditional Access, KQL, Logic Apps, Azure RBAC, Azure Policy, and Azure Cost Management.

## Projects

| Project | Focus |
|---|---|
| [Entra ID Identity Security Lab](entra-id-identity-security-lab/) | Users, groups, role assignment, MFA, Conditional Access, audit logs, sign-in logs |
| [Microsoft Defender for Cloud Security Posture Lab](Microsoft-Defender-for-Cloud-Security-Posture-Lab/) | Defender for Cloud setup, secure score review, recommendations, regulatory compliance, cloud security posture |
| [Microsoft Sentinel SOC Monitoring Lab](microsoft-sentinel-soc-monitoring-lab/) | Sentinel SIEM setup, Azure Activity logs, Entra sign-in/audit logs, KQL validation, analytics rules, alerts/incidents, workbook dashboard 
| [Azure Foundation Deployment Lab](azure-foundation-deployment-lab/) | Resource groups, virtual networks, subnets, NSGs, private VM deployment, storage account configuration |
| [Azure RBAC and Policy Lab](azure-RBAC-policy-lab/) | Service principal, custom Azure RBAC role, least-privilege access testing, Azure Policy enforcement, storage public access denial |
| [Azure Cost Monitoring Dashboard](azure-cost-monitoring-dashboard/) | Pay-As-You-Go cost control, budget alerts, tagging strategy, Cost Analysis views, Azure dashboard, cost governance |

## Purpose

The goal of this repository is to document practical Microsoft cloud security and Azure administration projects. Each lab focuses on building, configuring, testing, and documenting real cloud workflows that are relevant to entry-level cloud, SOC, and security operations roles.

These projects demonstrate hands-on experience with:

- Securing cloud identities
- Monitoring cloud activity
- Investigating alerts and logs
- Managing Azure resource access
- Enforcing governance policies
- Building cloud infrastructure
- Tracking and controlling cloud costs
- Documenting technical work clearly for a portfolio
